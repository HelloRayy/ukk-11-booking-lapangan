Kamus Lengkap File & Tanggung Jawab (Single Responsibility)

Setiap berkas memiliki 1 tugas spesifik agar kodingan rapi dan bersih sesuai standar UKK.

src/types/database.ts

Model / Skema Data: Mendefinisikan tipe data TypeScript untuk tabel lapangan dan bookings.

Kolom kunci: jam_slots (string[]), status ('Aktif' | 'Tutup'), no_hp (string).
src/lib/api.ts

Controller Backend: Mengeksekusi query SQL langsung ke Supabase (CRUD Lapangan, Cek Bentrok Jam, dan Pelunasan Kasir).

Fungsi kunci: getLapangan, createLapangan, updateLapangan, getBookedSlots, createBooking, getAllBookings, updateStatusBooking.
src/components/cashier/dashboard-01/CourtsManagementView.tsx

Kelola Master Lapangan: Halaman kasir untuk menambah data lapangan, menghapus lapangan, dan melakukan toggle status Aktif (Enable) <-> Tutup (Disable).

Aksi kunci: handleToggleStatus() memanggil updateLapangan(id, { status: 'Tutup' | 'Aktif' }).
src/components/cashier/dashboard-01/BookingsTable.tsx

Tabel Kasir & Pelunasan: Menampilkan seluruh transaksi, kotak pencarian nama, filter status, dan tombol aksi "Lunasi" (mengubah sisa bayar jadi Rp 0).

Aksi kunci: onLunasi() memanggil updateStatusBooking(id, 'Lunas', 0).
src/components/reservation/hooks/useReservationData.ts

Hook Reservasi Publik: Mengambil data lapangan dan booking. Memfilter lapangan yang berstatus Aktif saja sehingga lapangan 'Tutup' otomatis tidak bisa dibooking.

Logika kunci: const activeCourts = dbCourts.filter(c => c.status === 'Aktif').
src/utils/costCalculation.ts

Kalkulator Biaya: Menghitung total sewa dari durasi x tarif, serta membagi tagihan DP 50% dan sisa pelunasan.

Rumus: total = durasi * tarif, DP = total * 0.5, sisa = total - DP.
