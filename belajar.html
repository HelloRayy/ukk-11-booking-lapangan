Struktur Lengkap Proyek (100% Bahasa Indonesia)

Semua file memiliki satu tanggung jawab yang jelas (Single Responsibility Principle).

Komponen Halaman & Layout (`src/`)
src/App.tsx (44 baris)

Pintu gerbang aplikasi. Hanya mengatur tombol pemindah tab: Menu Pemesan vs Menu Kasir.

src/components/HalamanPemesan.tsx

Wadah yang menyusun Langkah 1 sampai 5 pemesanan.

src/components/HalamanKasir.tsx

Wadah menu kasir yang memuat tabel transaksi dan aksi pelunasan.

Komponen 5 Langkah Pemesan (`src/components/`)
PilihLapangan.tsx (Langkah 1)

Tombol pilihan Court 1, 2, 3 beserta tarif per jam.

GridJam.tsx (Langkah 3)

Kotak jam 08:00 - 21:00. Tombol otomatis terkunci jika sudah dibooking atau sudah lewat jamnya.

RingkasanBiaya.tsx (Langkah 4)

Tampilan durasi main, total biaya rupiah, dan nominal DP 50%.

FormPemesan.tsx (Langkah 5)

Form input nama, nomor HP, radio DP/Lunas, dan tombol simpan.

Komponen Modul Kasir (`src/components/`)
TabelKasir.tsx

Wadah tabel, judul laporan, tombol Refresh, dan tombol Cetak Rekap.

BarisKasir.tsx

Menampilkan satu baris transaksi dan tombol aksi Lunasi / Batal.

BadgeStatus.tsx

Label warna: Hijau untuk Lunas, Kuning untuk Booked, Merah untuk Batal.

Otak Logika, Rumus & Database (`src/hooks, utils, lib`)
src/hooks/usePemesanan.ts

Otak data pemesanan. Mengelola state court, tanggal, jam, dan kirim booking.

src/hooks/useJadwal.ts

Menarik jadwal yang sudah dibooking dari Supabase agar tidak nabrak.

src/utils/hitungBiaya.ts

Rumus matematika: total = durasi x tarif, DP = 50% x total, sisa = total - DP.

src/lib/api.ts

Kumpulan perintah Supabase: getLapangan, getBookedSlots, createBooking, updateStatusBooking.

Bocoran Tanya Jawab Penguji UKK

Hafalkan pola jawaban ini agar kamu percaya diri saat disidang penguji industri.

TANYA 1: "Bagaimana cara sistem mencegah jadwal bentrok jika 2 orang pesan di jam yang sama?"
Jawab: "Di file useJadwal.ts, fungsi getBookedSlots mengambil seluruh jam yang sudah dipesan di lapangan dan tanggal tersebut dari Supabase. Kemudian di GridJam.tsx, tombol jam dicocokkan menggunakan jamTerisi.includes(jam). Jika jam itu sudah ada di database, tombol otomatis diberi atribut disabled sehingga tidak bisa diklik lagi."
TANYA 2: "Coba ubah aturan uang muka DP dari 50% menjadi 30% sekarang juga!" (Live Code Challenge)
Jawab & Aksi: "Buka file src/utils/hitungBiaya.ts. Ubah baris const nominalDP = totalBayar * 0.5 menjadi const nominalDP = totalBayar * 0.3 lalu simpan file. Angka DP di browser otomatis berubah ke 30%."
TANYA 3: "Bagaimana alur pelunasan sisa bayar saat penyewa hanya bayar DP di awal?"
Jawab: "Saat pesan DP, transaksi tersimpan dengan status 'Booked' dan mencatat kolom 'sisa_bayar' sebesar 50%. Saat penyewa tiba di GOR, kasir membuka tab Menu Kasir (HalamanKasir.tsx) dan menekan tombol 'Lunasi'. Sistem menjalankan updateStatusBooking(id, 'Lunas', 0) yang mengubah status jadi Lunas dan mengosongkan sisa bayar menjadi 0."
TANYA 4: "Kenapa kodingannya dipecah menjadi banyak file dan komponen?"
Jawab: "Untuk mematuhi prinsip Clean Code (Separation of Concerns). Logika data dipisah ke dalam Custom Hook (usePemesanan), rumus matematika dipisah ke utilitas (hitungBiaya), dan komponen antarmuka murni menyusun layout. Ini membuat kode mudah di-maintain, mudah di-test, dan tidak menumpuk dalam satu file raksasa."
